# INC-001 — Test runner

## Executive Summary

This increment makes `npm test` a real command for BrickShop search. Today the script prints an error and exits 1, so later increments would have no gate.

The shop has no test suite. The parser work cannot be checked until a runner exists.

Use Node's built-in test runner. Do not add a test framework and do not load the language model.

## Increment Identity

#### Increment Identity

**Increment ID**: INC-001
**Increment Name**: Test runner
**FR Mapping**: None (foundational)

## Goal

#### Goal

The project can run an automated test command that exits 0 when the suite is empty of failures.

## Dependencies

#### Dependencies

None

## Plan

#### Plan

1. Set the `test` script in `package.json` to `node --test`.
2. Create `test/phrase-limits.test.js` with one passing test that imports nothing from the shop.
3. Run `npm test` and keep the command exiting 0.

## Outcome

#### Outcome

- `package.json` script `test` is `node --test`
- `test/phrase-limits.test.js` exists
- `npm test` exits 0

## Automated Verification (AI Gate)

#### Automated Verification (AI Gate)

1. Run `npm test` from the repo root.

**Expected**:

- The command exits 0
- The runner reports at least one passing test

## Human Verification (Human Gate)

#### Human Verification (Human Gate)

1. Confirm the script does not download packages at test time
2. Confirm the test file does not import `index.js` or open MySQL

## Success Criteria

#### Success Criteria

✅ `npm test` exits 0
✅ The runner is `node --test`
✅ No new test-framework dependency
✅ The smoke test does not touch the database
