# Process map (as-is)

Search as the shop works today. Derived from the catalog and the search page. Confirmed by the user on 2026-09-23.

1. A shopper opens search from the magnifying-glass control in the header. They do not need to sign in. No words are typed yet, so the page lists products whose English name matches an empty search, which is the full English-name list, 20 at a time, cheapest first.
2. On the search page they type words and submit. The shop returns products whose English name contains those words, still 20 at a time.
3. They can choose a price order (low to high, or high to low) or a single category. Changing either one submits immediately. Those controls do not keep the words just typed, so the list drops back to a category or price sort without the typed words.
4. If more than 20 products match, they move between pages. Page links do keep the words, the category, and the price order.
5. They open a product from the list. From that product they can comment or use the cart, which is outside search.
6. If nothing matches, the page says no products are available.
