# User journey map

Derived from the search page. The user marked where the change lands on 2026-09-23.

## Journey A — find a product by typing

**Where the change lands:** steps 3 and 4. Opening search, paging, and opening a product stay as they are.

1. The user opens search from the header magnifying glass. No sign-in. Unchanged.
2. The page asks what they are looking for and shows a search box, a price order, a category list, and a product grid. Unchanged.
3. **Change.** They type an ordinary phrase, not a product-name fragment. The phrase can carry a description (for example, "red colored toy") and a limit (for example, "under $50").
4. **Change.** The shop turns that phrase into a structured search — the attributes and limits inside the phrase — and shows the products that match. Today the shop only matches words inside the English product name. It does not turn a phrase into color, kind of toy, or a price limit.
5. They open a product from the results, or they see that no products are available. Unchanged.

## Journey B — open search without typing

Unchanged. With no phrase, the user sees the full English-name list, cheapest first, 20 at a time, and can page, change price order or category, or open a product.

## Journey C — narrow the list after typing

Unchanged. The separate price-order and category controls stay as they are, including the current behavior of dropping the typed words when either control is changed.
