# User journey map (future)

Confirmed by the user on 2026-09-23. Drawn from the discovery journey map and the future process.

## Journey A — find products by a phrase

1. The user opens search from the header magnifying glass. No sign-in. Unchanged.
2. The page shows the search box, the price order, the category list, and a product grid. Unchanged.
3. **Change.** They type an ordinary phrase. The shop reads it for an English list-price cap, a theme, and an age. Other words are dropped.
4. **Change.** If none of those three is in the phrase, they see no products. If one or more are present, they see the interpreted limits and only products that satisfy every one of them. A product at exactly $50 is included in "under $50." An empty product list still shows the limits.
5. They open a product from the results, or they see that no products are available. Unchanged.
