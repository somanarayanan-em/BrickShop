# UX design

The shopper still opens search from the header and types in the existing box.

After submit, the page shows the interpreted limits in one line above the products: the theme fragment, the price bound in dollars, and the age bound. Example: "Ninjago, $10–$50, ages 5–12." An empty product grid still shows that line. A phrase with no bound shows neither the line nor products.

Empty search, with no phrase, keeps today's full list and does not show a limits line.

Trace: FR1.1.8, FR2.1.1.
