# Glossary

| Term | Meaning |
|---|---|
| Phrase | Words submitted on the search page. |
| English list price | `p_price_en`, before discount. |
| Bound | A price minimum, a price maximum, an age minimum, an age maximum, or a theme fragment. |
| Language step | Local model plus parser inside the Express app. |
| Closed grammar | `under N`, `over N`, `between A and B`, `age N`, `ages A-B`, plus theme words. |
